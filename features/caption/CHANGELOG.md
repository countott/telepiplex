# Telepiplex Caption 更新记录

## 1.3.3 · 2026-10-13 · 本地源码，待用户发布

- 匹配阶段分别核对结构化字段、发布名与成员季集证据，拒绝明确冲突，保留正确整包、显式映射及剧集首播年和季度年份差异；排除分辨率与 CRC 的年份误识别。

- 只对确定会进入最终轮询候选池的条目提前下载检查，保留候选预算、来源顺序与线程并发边界；匹配与排序仍逐请求执行。

- 验证、受控性能及公网样本边界见 [迭代交付](../../docs/audits/2026-10-13-iteration-results.md)。

## 1.3.0 · 2026-10-05 · 本地源码，待用户发布

- 将默认检索调整为“精简常用”：ASSRT、SubHD、迅雷为通用来源；电影补充 R3SUB，剧集补充 Addic7ed。保留全部 18 个适配器，不将站点数量视为独立字幕库存数量。
- 字幕库与 Subf2m 保留详情链接入口，LWLTV 移到“全部来源”方案。未配置 Key、视频哈希、归档路径的来源在排队前跳过；YYSub 在精简方案需登录 Cookie，已确认真人作品不查询动画目录。未知分类保持目录覆盖。
- `/caption_config` 增加“精简常用／全部来源”选择，旧配置缺少 `source_profile` 时采用精简方案；原有来源授权与 `enabled` 值保留。两个有 Key 的 SubDL／SubSource 仍一起参加正文选优，避免把历史交集误当作新增内容相同。
- 指定详情链接只查询对应适配器，仍尊重禁用设置与来源额度冷却。结果记录实际参与与跳过原因，无适用来源不再误报站点故障。
- 字幕正文质量、语言优先级和 chi／cht 命名规则保持；Host、其他 Feature、SDK 与 API 版本保持。

评估证据、当前网站复核、配置兼容与验证见[来源简化交付记录](../../docs/audits/2026-10-05-caption-source-simplification.md)。

## 1.2.0 · 2026-10-03 · 本地源码，待用户发布

- 将 `/caption` 与 `/caption scan` 统一为与 Rename 对齐的任务面板：目录菜单每页 8 项，支持翻页、输入其他目录和单独查找字幕。
- 目录扫描完成后展示视频数量，点击“开始补字幕”后才检索和写入；直接指定扫描路径同样需要确认。选择、进度与取消复用同一任务面板。
- 作品候选展示编号、中外标题、年份、国家／地区及媒体类型，支持按钮和回复编号。批次内遇到同名作品或缺少原始语言时暂停确认，再从当前文件继续。
- 配套 Host 3.9.1 清理异步任务结束后残留的输入会话，避免 Caption 完成、失败或取消后影响下一条作品链接。
- 保留快捷 query、`scan` 路径和 `--source` 入口；配置字段、字幕来源、质量检查、chi/cht 命名及其他 Feature／SDK 版本保持。`/caption_config` 本轮未重构。

## 1.1.0 · 2026-09-28 · 本地源码，待用户发布

- 扩展为 18 个适配器：保留 ASSRT、Shooter、OpenSubtitles；完善 SubHD／字幕库正常公开下载；加入迅雷、SubDL、SubSource、Subf2m、R3SUB、Addic7ed、LWLTV、YYSub、四个字幕组目录及本地归档。
- SubHD 可使用匿名 session；字幕库、Subf2m 的搜索故障明确报告，并可通过 `/caption <作品query> --source <正规详情地址>` 使用已知条目。网站 Cookie、免费 Key 与文件 CDN 凭据严格分离。
- 动漫仅使用有成品证据的文件，绝对集号需要来源证据或用户映射；本地归档默认不扫描任何目录，可使用受限目录与 TSV 索引。
- 以真实正文区分简繁、单语／双语，补充分段、未完成制作素材及剪辑版本拒绝；7z 在独立受限进程中解包。选择规则和 Plex `chi`／`cht` 命名保持。
- 请求合并、缓存、免费配额退避及实际线程容量有界。单媒体默认 180 秒，超时仍保留已经完成内容检查的字幕，包括整季包内已完成的单集；用户取消仍立即停止后续写入。
- 配套 Search 2.6.0 提供已确认电影／明确季集的参考时长；保留无视频独立查询。Download 2.2.0、Rename 2.4.0、Host 3.9.0、SDK 2.2.1 与既有 Plex 接续兼容。

真实网站、免费 Key 未授权范围、媒体库样本、压测和文件清单见[交付审计](../../docs/audits/2026-09-28-caption-free-providers-delivery.md)。网站限制不视为字幕不存在；未声称付费源、验证码或未授权 API 已通过。
