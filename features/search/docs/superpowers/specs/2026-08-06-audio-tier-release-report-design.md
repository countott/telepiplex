# Search 片源音频层级与紧凑展示设计

**日期：** 2026-08-06
**状态：** 用户已确认
**范围：** Search Feature 的 Prowlarr 结果文案

## 目标

片源列表只展示影响用户选择的规格，音频按体验能力分层，不再把有损、无损或底层编码作为主标签。

## 展示结构

标题栏承载搜索范围：

```text
✅ 怪奇物语 · 第1季整季
搜索器 8/(10-2)，离线 2
```

电影整片不追加范围。每个片源固定两行，相邻片源之间不插入空行：

```text
① 2160p · WEB-DL · DV · 8ch沉浸
   48.6 GB｜活种
② 1080p · WEB-DL · HDR10 · 6ch环绕
   18.2 GB｜疑似死种
```

规格顺序固定为：

```text
分辨率 → 来源 → 画面特性 → 版本 → 音频层级
```

视频编码、音频格式、发布组、搜索器名称和内部评分不展示。

## 音频层级

- 明确 Atmos、DTS:X 或 Auro-3D 时归为 `沉浸`。
- 明确声道数时，以各布局数字之和换算总声道数，例如 `5.1 -> 6ch`、`7.1 -> 8ch`、`5.1.2 -> 8ch`。
- 沉浸格式已确认但声道未知时显示 `?ch沉浸`。
- 非沉浸的多声道格式显示 `Nch环绕`。
- `2.0` 或 `2CH` 显示 `2ch立体`。
- 声道和沉浸能力都无法确认时显示 `?ch`。
- FLAC、TrueHD、DTS-HD、EAC3、AAC 等格式只参与内部识别，不能单独推断声道，也不直接显示。

## 版本

该用户可见能力作为 Search Feature 次版本升级发布，版本从 `1.6.0` 提升到 `1.7.0`。
