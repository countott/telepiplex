# rename 外挂字幕整理设计

## 目标

在现有 `/rename` 存量扫描与下载后整理链中，把 `.srt`、`.ass`、`.sup`、`.vtt` 外挂字幕纳入与视频共享的规划、冲突预检、执行验证和源目录清理流程。字幕可以与视频跨目录、稀疏覆盖季度，也可以作为纯字幕任务合入已有作品目录或建立仅含字幕的规范目录。

## 身份与映射

- 作品身份仍由 `content_probe -> media.search.resolve_metadata -> confirmed media_metadata` 确认。
- 视频和字幕分别提取路径证据，最终以 `series_scope_key + season_number + episode_number` 汇合，不依赖同目录或原始同名。
- 字幕优先使用明确 `SxxExx`、`x` 格式、中文季集、季目录加裸集号、同批视频原名关系；确定性证据不足时，只允许 AI 在已确认作品和允许季集范围内补映射。
- 多季资源中只有裸集号且无法确定季度时，整项保持原位，不猜测、不清理。
- 字幕可以只覆盖部分剧集；不要求与视频数量一致。

## 字幕语言策略

资源库只保留以下外挂字幕：

1. 简体中文加英文双语字幕，目标后缀 `.chi`，优先级最高。
2. 简体中文单语字幕，目标后缀 `.chi`，仅在同集没有中英双语版本时保留。
3. 明确繁体中文、英文单语及其他语言全部排除。
4. 无法判断语言的字幕阻断当前直接子项，不能当作排除项删除。

支持源格式 `.srt`、`.ass`、`.sup`、`.vtt`，保留原字幕扩展名。目标示例为 `Veep S03E04.chi.ass`。

## 合并与原子计划

- 目标作品目录和季目录允许已经存在；已有规范视频作为免写锚点。
- 视频、字幕、已有免写项和明确排除项组成同一 `OrganizationPlan`。
- 所有目标冲突在第一次写操作前统一检查。同路径同内容视为幂等；同路径不同内容阻断且不覆盖。
- 115 不提供物理事务，因此执行采用串行操作、写后验证、完整成功后延迟清理。任何未解决映射或预检冲突都在写入前阻断。
- 纯字幕任务可以合入已有作品，也可以创建仅含字幕的作品与季目录。

## 新版终态

- 电影允许 `English Title.ext` 与 `English Title.chi.<subtitle-ext>`。
- 剧集允许 `English Title SxxExx.ext` 与 `English Title SxxExx.chi.<subtitle-ext>`。
- 只有字幕时也允许上述字幕结构成为已完成终态。
- 繁体及其他已排除字幕不进入目标资源库。

## 验证范围

- 四种字幕扩展名。
- 视频分季目录、字幕平铺根目录。
- 字幕只覆盖部分季度或剧集。
- 纯字幕合入已有目录与新建目录。
- 简英优先、简中次选、繁中和其他语言排除、未知语言阻断。
- 目标冲突、重复执行和源目录清理失败。
- 现有电影、单集、整季、全剧和 `/rename` 扫描回归。
